## 1. 能力基线与 12 周目标

你已经具备 React、TypeScript、Next.js、状态管理、接口联调和三个完整项目，不需要再通过新建普通 CRUD 证明“会写页面”。当前最重要的任务是把已有能力变成更可信的就业证据：

- **TaskFlow**：从 BaaS 使用者升级为能自建 PostgreSQL、Session、API、测试和部署的前端偏全栈开发者。
- **RedditLike**：证明你能维护 React 19 实时业务 UI，并处理复杂交互、测试、a11y 和性能。
- **U-s-cinema**：形成可访问、可降级、与真实业务状态联动的 Web 3D 代表功能。
- **求职**：从第一周持续投递，用面试漏斗决定后续补强，不等待 Gate B。

12 周成功不等于“学完所有技术”，而是同时满足：

1. TaskFlow 达到 Gate B。
2. RedditLike 有测试、复杂交互 a11y、CI 和一项测量改进。
3. Cinema 有在线 R3F 影廊、业务联动和降级。
4. 个人站三链、三份演示脚本、简历证据一致。
5. 累计约 120 次有效投递、8 次真实或模拟面试复盘。

## 12. 三项目完成定义与 60 秒脚本

### 12.1 TaskFlow

**完成定义：** 自建 PG/API/Session/归属；浏览器 CRUD/筛选；在线、本地启动、集成测试、E2E、CI 和案例文档齐。

**60 秒脚本：**

1. 0–10s：登录并指出使用数据库 Session + HttpOnly Cookie。
2. 10–30s：创建任务，展示字段校验、列表更新和刷新后持久化。
3. 30–45s：使用 URL 筛选/分页，并打开 Network 指出 Fastify API。
4. 45–60s：展示 CI/测试，并用一句话说明用户归属防越权。

### 12.2 RedditLike

**完成定义：** Tailwind 迁移边界清晰；复杂交互 a11y；实时 pending/error；关键测试、CI 和一次测量优化。

**60 秒脚本：**

1. 0–15s：打开 Feed，演示 loading/empty/实时数据体验。
2. 15–30s：投票或发布，展示 pending、防重复和实时反馈。
3. 30–45s：键盘打开/关闭 Dialog 或 Dropdown，展示焦点恢复。
4. 45–60s：展示测试/CI和一次 Profiler 前后证据。

### 12.3 Cinema

**完成定义：** TS 事实一致；普通电影功能稳定；懒加载 R3F 影廊与业务联动；降级、性能和测试证据齐。

**60–90 秒脚本：**

1. 0–15s：进入独立影廊路由，说明 3D chunk 懒加载。
2. 15–40s：选择海报，将 movieId 同步到详情，并执行收藏/想看。
3. 40–60s：展示 DOM 等价列表或 reduced-motion/移动端降级。
4. 60–90s：说明 DPR、按需渲染、纹理预算和资源清理。

## 14. 12 周后的方向决策
